# Epoch design system

## Direction

Theme 01 is an editorial publication for Solana communities. It prioritises readable stories, clear navigation and an identifiable cover illustration over financial dashboards, live price tickers or promotional urgency.

The first iteration's green-tinted palette was rejected during owner review. The accepted direction is **charcoal + blue**. Header navigation and sidebar block spacing must be tested in native WordPress output, not inferred from a static HTML preview.

## Tokens

- Canvas: `#101216`
- Surface: `#191c22`
- Raised: `#222731`

- Ice accent: `#b5cfff`

- Body: operating-system sans; metadata: operating-system monospace.
- Content width: 1240px; article measure: 780px.
- Desktop nav gap: 24px; minimum primary control height: 44px.
- Cards: 28px columns / 36px rows; narrow view: one column / 32px rows.
- Sidebar sections: 32px separation in native WordPress.
- Header tagline: 10px monospace, never inherited from the site-title size.

## Composition

Large editorial hero, original orbital illustration, wrapping topic chips, story grid and reading rail. The hero is a homepage component; articles use a narrower reading layout. Sidebar widgets become a lower reading section on mobile. Footer includes publication navigation and a discreet removable Gonk credit.

## Motion

Only a decorative cover orbit and short hover feedback. No ticker, autoplay video, count-up earnings or flashing button effects. Reduced-motion disables nonessential motion. Content is visible without JavaScript.

## What makes later themes different

This is one design. A colour variation is not a new theme. Future themes should change composition, navigation, hierarchy, card structure and content needs for their audience. Keep a catalogue entry explaining each design's differences.
