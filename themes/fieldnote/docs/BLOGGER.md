# Fieldnote for Blogger

1. Back up your current theme: Blogger → Theme → ⋮ → Backup.
2. Extract the ZIP. In Blogger → Theme → ⋮ → **Restore**, upload `fieldnote-blogger.xml`.
3. Blogger → Settings → Favicon: upload `assets/fieldnote-favicon-96.png`.
4. Use labels **Birds, Plants, Fungi, Weather, Trails, Notes** on your posts for the field-guide chips.
5. Create a page with the URL `/p/about.html` for the "About this journal" link, or edit that link in the theme HTML.
6. **Margin notes** in a post: switch the post editor to HTML view and add
   `<aside class="fn-margin"><b>Margin note</b>Your aside here.</aside>`
7. Layout → *Field links* (an HTML gadget) and *Pages* are editable. Other default gadgets are hidden for a clean surface.
8. The **Powered by gonk.fun** credit is in the footer of the theme HTML; edit or remove it freely.
