# Fieldnote for WordPress

1. Appearance → Themes → Add New → Upload Theme → choose `fieldnote-wordpress-1.0.0.zip` (do not unzip). Activate.
2. Create categories **Birds, Plants, Fungi, Weather, Trails, Notes** (or edit the *Field guide topics* pattern).
3. Give each entry a featured image: a photo or a drawing.
4. While writing, insert patterns from the **Fieldnote sections** category:
   - **Observation details line:** date · place · weather under the title.
   - **Margin note:** a side annotation. You can also select any Group and choose the *Margin note* style.
5. Appearance → Editor lets you change the header, homepage, field kit, footer and colours. The **Powered by gonk.fun** footer credit can be edited or removed there.
6. Southern hemisphere: add `data-fieldnote-hemisphere="south"` to the `<html>` element (for example with a small code-snippet plugin), so the season label flips.

Requirements: WordPress 6.6+, PHP 7.4+, a host that allows custom theme uploads (WordPress.com free plans do not).
