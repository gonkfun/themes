# Install Panelwork on Blogger

1. Choose your blog and save its current theme from **Theme → More → Backup**.
2. Extract the Blogger ZIP. In **Theme → More → Restore**, upload `panelwork-blogger.xml`.
3. Set your title and description in **Settings**. Use **Layout** to organize the Pages and Topics gadgets.
4. Publish posts with labels. The dashboard chart groups the dates Blogger provides for the current list. If no dates are available, the theme displays an empty chart message.
5. Use **Settings** to control comments. The search box searches the whole blog. The post filters apply only to the current page.

The footer credit can be edited or removed in **Theme → Edit HTML**. Appearance selection stays in the visitor's browser. The theme adds no trackers, fonts from other sites, or external scripts.
