# Signal Atelier

A bold studio portfolio with an oversized opening, a structured service list and case-study templates.

[Live preview](https://gonkfun.github.io/themes/signalatelier/) ·
[Blogger and WordPress downloads](https://github.com/gonkfun/themes/releases/tag/signalatelier-v1.0.0)

For Blogger, extract the ZIP and restore `signalatelier-blogger.xml`. [Blogger setup guide](blogger/INSTALL.md).

Upload the WordPress ZIP under **Appearance → Themes → Add New → Upload Theme**.
Use **Appearance → Editor** to edit the site title, navigation, Home template patterns and footer.
Publish posts to populate the latest entries. For a separate posts page, set one under **Settings → Reading**.

GPL-2.0-or-later. CSS artwork and theme code are original. The theme works without plugins or remote assets.

The Blogger XML and archive are checked in CI. A live Blogger restore has not yet been verified.
