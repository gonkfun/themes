# Lumen for Blogger

1. In Blogger, choose your blog and open **Theme → More → Backup** to save the current theme.
2. Extract the Lumen ZIP. Choose **Theme → More → Restore** and select `lumen-blogger.xml`.
3. Set your site title, description and favicon in **Settings**. The title and description appear on the journal homepage.
4. Publish a post with a title, image and label. The newest homepage entry becomes the featured essay. Labels feed the topic links on article cards and in the footer.
5. Under **Layout**, configure the Topics and Pages gadgets. Under **Settings**, choose whether to allow comments.
6. Readers can select System, Light or Dark. The selection stays in their browser.

Remove or edit the Gonk credit in the footer through **Theme → Edit HTML**. It is a nofollow link.

The XML, widget structure and ZIP are checked in CI. A live Blogger restoration has yet to be verified.
